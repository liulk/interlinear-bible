# README

This is a trilingual interlinear study Bible of Hebrew/Greek with
English and Chinese direct translations, compiled from the following
sources:

  * The original English interlinear XML was forked from
    [DannyCarlton/xmlBible.org@f14f0c7] ([tree]), licensed under [GPL 3.0].
  * Chinese parsing from [fhl.net public PostgreSQL dump][fhl],
    licensed under [GNU FDL 1.1].
  * Strong's and KJV definitions of Hebrew and Greek from
    openscriptures/strongs. The JSON version is licensed under
    CC-BY-SA.
